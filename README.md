# Sili Store — متجر كورسيهات شد ونحت

موقع متجر ثابت (Static) لعرض كورسيهات الشد والنحت مع الأسعار، وإمكانية استقبال الطلبات عبر **واتساب** أو **نموذج الموقع**.

## الملفات

- `index.html` — الصفحة الرئيسية للمتجر
- `styles.css` — تنسيقات المتجر
- `app.js` — إعدادات المتجر وسلوك الطلب
- `products.js` — **مصدر منتجات المتجر** (يقرأه الموقع ولوحة التحكم)
- `admin/index.html` — لوحة التحكم
- `admin/admin.css` — تنسيقات لوحة التحكم
- `admin/admin.js` — منطق لوحة التحكم
- صور المنتجات (`.jpg`) — صور المنتجات المعروضة

## التخصيص السريع

افتح ملف `app.js` وعدّل قسم `STORE`:

```js
const STORE = {
  name: "Sili Store",
  whatsappNumber: "963991189602", // رقم واتساب بصيغة دولية بدون +
  whatsappDisplay: "0991189602",
  formEndpoint: "", // رابط Formspree لاستقبال الطلبات عبر الموقع
  currency: "ر.س",
};
```

## لوحة التحكم (/admin)

تم إضافة لوحة تحكم في المسار:

- محلياً: `http://localhost:8000/admin/`
- بعد النشر: `https://USERNAME.github.io/REPO/admin/`

### الدخول

- **كلمة المرور الافتراضية:** `admin123`
- غيّر كلمة المرور فوراً من زر **"تغيير كلمة المرور"** داخل اللوحة.

### ماذا يمكنك أن تفعل من لوحة التحكم؟

- إضافة منتج جديد
- تعديل منتج (الاسم، السعر، الوصف، الشارة، الصورة، الحالة)
- إخفاء/إظهار منتج
- حذف منتج
- تصدير ملف `products.js` المحدّث
- نسخ بيانات المنتجات بصيغة JSON
- استعادة المنتجات من الملف الأصلي المنشور

### مهم جداً بشأن النشر

الموقع مستضاف على GitHub Pages كموقع ثابت، لذلك:

1. التعديلات داخل لوحة التحكم تُحفظ كـ **مسودة في متصفحك**.
2. لكي يرى الزوار التغييرات، اضغط **"تصدير products.js"**.
3. استبدل ملف `products.js` في المستودع بالملف المصدّر.
4. ارفع التحديث إلى GitHub (commit/push).

> **تنبيه أمني:** حماية لوحة التحكم هنا هي حماية واجهة على موقع ثابت (Client-side). كلمة المرور يتم التحقق منها عبر Hash في المتصفح، لكن هذا **ليس أمناً بالكامل** مثل أنظمة الخادم. لا تستخدمها لحماية بيانات حساسة، ولأمان أعلى استخدم استضافة بخادم وقاعدة بيانات ونظام مصادقة حقيقي.

## استقبال الطلبات

### 1) واتساب

يعمل مباشرة بعد وضع رقم واتساب الصحيح في `whatsappNumber`.  
عند إرسال الطلب، يتم فتح واتساب برسالة جاهزة تحتوي على بيانات العميل والمنتج والمقاس.

### 2) عبر الموقع (Formspree)

الموقع ثابت ولا يحتوي على خادم، لذلك لاستقبال الطلبات داخل الموقع استخدم خدمة نماذج مثل [Formspree](https://formspree.io):

1. أنشئ حساباً ونموذجاً جديداً في Formspree.
2. انسخ رابط النموذج.
3. ضعه في `formEndpoint` داخل `app.js`.
4. زر **"إرسال عبر الموقع"** سيعمل تلقائياً.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع ملفات المشروع إلى المستودع (الفرع `main`).
3. من GitHub: **Settings > Pages**.
4. في **Build and deployment** اختر:
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)`
5. احفظ الإعدادات. بعد دقائق سيعمل الموقع على رابط GitHub Pages.

## تشغيل محلياً

يمكنك فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط:

```bash
# Python
python -m http.server 8000
```

ثم افتح: `http://localhost:8000`

## ملاحظات

- غيّر كلمة مرور لوحة التحكم الافتراضية (`admin123`) فوراً.
- غيّر رقم واتساب قبل النشر.
- تأكد من صحة أسماء ملفات الصور داخل `products.js` أو عند الإضافة من لوحة التحكم.
- بعد أي تعديل من لوحة التحكم، لا تنسَ تصدير `products.js` ورفعه إلى GitHub.
